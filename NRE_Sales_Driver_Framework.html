NRE User × Freq × Sales Driver Analysis Framework

用于分析NRE用户变化、频次变化与Sales涨跌之间的量化关系

STEP 0

核心业务问题

  • NRE增长了，为什么Sales没有增长？
  • NRE下滑了，Sales受影响多少？
  • Freq下降1%，将损失多少Sales？
STEP 1

Sales本质拆解

Sales = User × Freq × AC

任何Sales变化最终只能来自：用户(User)、频次(Freq)、客单价(AC)

STEP 2

NRE Sales拆解

Sales(NRE)=User(NRE)×Freq(NRE)×AC(NRE)
ΔSales = User Impact + Freq Impact + AC Impact

计算公式

User Impact=(UserTY-UserLY)×FreqLY×ACLY
Freq Impact=UserTY×(FreqTY-FreqLY)×ACLY
AC Impact=UserTY×FreqTY×(ACTY-ACLY)
STEP 3

Freq下降的根因分析

Overall Freq = Σ(User Share × Segment Freq)

Freq变化需要拆解为Mix变化和Behavior变化。

Driver定义
Mix Effect用户结构变化导致
Behavior Effect同类型用户行为变化导致
STEP 4

Freq Decomposition

Freq Change = Mix Effect + Behavior Effect

NRE → New / Reactive / Existing

Existing → Heavy / Medium / Light

量化Freq下降到底来自结构恶化还是用户行为恶化。

STEP 5

归因到Sales

DriverImpact
New User Growth+80M
Reactivation+20M
Freq Decline-130M
AC Increase+15M
Total-15M
一句话：究竟是谁拖累了Sales。
STEP 6

Elasticity Model

ln(Sales)=β1ln(User)+β2ln(Freq)+β3ln(AC)
DriverElasticity
User0.35
Freq0.82
AC0.18

Freq弹性越高，说明频次是最关键增长杠杆。

STEP 7

Action Playbook

DiagnosisAction
User下降拉新
Mix恶化提升Reactive占比
Behavior下降提升2nd/3rd Order
Heavy流失保Heavy策略
