🔬 因果推断 · PSM 与 DID 准实验方法对比

📌 两种主流方法 —— 用于处理观察性数据中的选择偏差，评估政策、干预或处理的因果效应。

倾向得分匹配 (PSM) Propensity Score Matching

核心思想：通过估计每个个体接受处理的概率（倾向得分），将处理组与对照组中倾向得分相近的个体进行匹配，从而模拟随机化实验，控制可观测的混淆变量。

适用场景

  • 处理分配依赖于可观测特征（如年龄、性别、收入等）
  • 希望评估某项干预（如培训、医疗方案）对结果的因果效应
  • 数据为横截面或重复横截面，且处理组与对照组存在系统性差异

操作步骤

  1. 估计倾向得分：使用Logit/Probit模型，以处理变量为因变量，协变量为自变量，计算每个个体的倾向得分 p(X)。
  2. 选择匹配方法：常见方法有最近邻匹配、半径匹配、核匹配等，确定处理组与对照组的配对。
  3. 平衡性检验：检查匹配后协变量在两组间是否分布均衡（如标准化差异 < 0.1）。
  4. 估计处理效应：比较匹配后处理组与对照组的平均结果差异，即平均处理效应（ATT）。
✅ 优点： 能有效控制可观测的混杂因素，方法直观，易于实现。
❌ 缺点： 要求共同支持假设（重叠区域）；无法控制不可观测的混杂；对样本量有一定要求。
📘 示例：
研究职业培训对工资的影响。使用PSM，将参与培训的员工与未参与但在年龄、教育、经验等特征上相似的员工匹配，比较两组工资差异。

双重差分 (DID) Difference-in-Differences

核心思想：利用面板数据或重复截面数据，比较处理组和对照组在处理前后的变化差异，从而消除不随时间变化的不可观测混杂因素。

适用场景

  • 存在一个外部的政策或事件冲击，且冲击影响一部分群体（处理组），不影响另一部分（对照组）
  • 拥有至少两期数据（处理前/后）
  • 关注政策实施带来的平均因果效应

操作步骤

  1. 设置组别与时期：定义处理组（受政策影响）和对照组（未受影响），明确处理前和处理后时期。
  2. 计算双重差分：估计方程 Y = α + β·Treat + γ·Post + δ·(Treat×Post) + ε，系数 δ 即为DID估计量。
  3. 检验平行趋势假设：验证处理组和对照组在政策前的变化趋势是否平行（必要前提）。
  4. 稳健性检验：如安慰剂检验、改变窗口期等。
✅ 优点： 能控制不随时间变化的不可观测混杂（如地区文化、个体能力）；可结合面板固定效应。
❌ 缺点： 严重依赖平行趋势假设；对时间周期和数据质量敏感；外推能力有限。
📘 示例：
某城市提高最低工资标准，以相邻城市为对照，比较两地在政策前后就业率的变化，差分结果即为政策效应。

⚖️ PSM 与 DID 对比总览

维度 PSM DID
核心假设 可忽略性（给定协变量，处理分配独立于潜在结果） 平行趋势（处理组与对照组结果趋势在无处理时相同）
数据类型 横截面 / 重复横截面 面板数据 / 重复横截面（至少两期）
控制偏差来源 可观测的混杂因素 不随时间变化的不可观测混杂
主要优点 直观、易于实现，可处理高维协变量 控制固定效应，允许不可观测的组间差异
主要缺点 不能处理不可观测混杂；依赖共同支持假设 依赖平行趋势假设；对政策外生性要求高
常用扩展 核匹配、分层匹配、CEM（粗化精确匹配） 多期DID、合成控制法、事件研究法
💡 选择建议： 若主要担忧可观测的选择偏差，且缺乏面板数据，PSM是好的选择；若政策冲击明确，拥有多期数据且担心不可观测固定效应，则DID更合适。两者可结合使用（如PSM-DID）以增强稳健性。

🔗 组合应用：PSM-DID —— 先用PSM为处理组匹配对照，再对匹配后的样本进行DID估计，可同时控制可观测与不随时间变化的不可观测混杂，提高因果推断的可信度。

📌 本讲解基于计量经济学常用方法，适用于政策评估、项目效果分析等领域。
